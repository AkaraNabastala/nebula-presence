# Audit Nebula Presence — Oktober 2026

## Temuan sebelum perbaikan
- Sinkronisasi jadwal menggunakan cast PostgreSQL `COUNT(*)::int`, sementara adapter database lokal meneruskan query ke SQLite; log menunjukkan error sintaks.
- Ketika inner join jadwal menghasilkan nol baris, log hanya menyebut relasi secara umum, belum menunjukkan relasi mana yang hilang.
- Respons HTML dari server Vite dianggap sebagai respons HTTP yang valid meskipun bukan JSON API, sehingga kesalahan pemilihan port sulit dipahami.
- Menu navigasi menampilkan Manajemen Database, Backup Database, dan Pulihkan Database sebagai tiga halaman terpisah.
- Tema langit memiliki CSS fase waktu tetapi tidak dihitung sebagai gradasi kontinu berdasarkan waktu lokal.
- File environment dan unggahan restore lama tersimpan dalam branch publik.

## Perubahan pada branch audit-comprehensive-2026-10
- Mengubah hitungan sumber jadwal ke `COUNT(*) AS count` yang kompatibel dengan SQLite/PostgreSQL.
- Menambahkan diagnosis left-join per jadwal yang mencatat assignment, guru, kelas, atau mata pelajaran yang tidak ditemukan.
- Menjelaskan respons HTML non-JSON sebagai indikasi URL/port mengarah ke frontend, dengan saran memakai backend Portal lokal pada port 5000.
- Menyatukan Backup dan Restore di halaman Manajemen Database berbasis tab. URL lama diarahkan ke tab yang sesuai agar bookmark lama tetap bekerja.
- Mengurangi navigasi sistem menjadi satu entri Manajemen Database.
- Menambahkan interpolasi warna langit berdasarkan jam lokal, transisi CSS bertahap, dan palet yang tetap menghormati mode terang/gelap.
- Menambahkan ignore rules untuk file environment/database/upload lokal dan menghapus file environment serta unggahan restore lama dari versi branch ini.
